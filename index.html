ISL Bridge

Python, MediaPipe, scikit-learn, Streamlit

Recognises Indian Sign Language greetings from a camera or a short video clip. MediaPipe tracks 21 points on each hand and 33 on the body, each clip is resampled to 32 frames of 184 numbers, and a Random Forest picks the word. Below 40% confidence it says "not sure" instead of guessing.

88.4% accuracy when tested on a signer the model had never seen (nine words, six signers, trained on the public INCLUDE dataset). A college team project.

WALL-E and EVE's Signal

Python, NumPy, Bayesian inference

An autonomous agent that explores a simulated map, collects noisy clues, manages a limited battery and works out where EVE is. It keeps a probability grid over her location, updates it after every reading, and picks its next move by how much it expects to learn versus how far it must travel. It never strands itself: getting back to a charger is a hard rule, not a reward.

98 to 100% of 50 random missions per profile ended within 1.5 cells of EVE, with 25 unit tests and CI on Python 3.10 to 3.12. Pure Python and NumPy, no game engine.

Phone Controller

HTML, JavaScript, Node.js, WebSockets

Turns a phone into a real-time motion controller for a browser game running on a laptop. Scan a QR code or type a room code, and tilting the phone steers the game. Built for the "Anything but a Game Controller" challenge.

WattGrid

Python, Isolation Forest, anomaly detection

An AI-powered system for detecting potential electricity waste in classrooms and labs. It uses an unsupervised Isolation Forest model trained on occupancy, device state and power consumption data. This was my project at DevJams '26.
